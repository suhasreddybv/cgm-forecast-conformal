# Data: OhioT1DM

**This dataset is under a data use agreement. Nothing from it, raw or derived, may be committed to this repository or redistributed in any form.** That includes processed CSVs, per-patient figures that expose raw traces, model checkpoints trained on it and cached features.

- Access: request through Ohio University under the OhioT1DM data use agreement (Marling & Bunescu, 2020).
- Place the XML files at `data/OhioT1DM/{train,test}/<patient_id>-ws-{training,testing}.xml`.
- `data/` is gitignored except this file. Only aggregate metrics may appear in `results/` and `figures/`.
